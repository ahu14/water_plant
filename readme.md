# Water Plant

Using ESP-32 S3 Wokwi Simulator. First time studying embedded / electronics.

<a href="https://wokwi.com/projects/475110707201127425">Project</a>


## Features

- 3 sensor (potentiometer, temperature, and photoresistor)

- Using MQTT to send data in json format

- Using WiFi to connect to MQTT

- Using SPI display to show current plant status and give recommendation based on current weather and temperature


## How to run project

1. Open this project at <a href="https://wokwi.com/projects/475110707201127425">Wokwi</a>

2. Click "Run Simulation"
